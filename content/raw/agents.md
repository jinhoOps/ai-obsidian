# 📦 Raw Layer — AI 운영 규칙

> 이 파일은 `content/raw/` 레이어에서 AI 에이전트가 준수해야 할 규칙을 정의합니다.

---

## 레이어 정의
**Layer 1: 불변 원본 소스** — 사용자가 직접 수집·저장한 원본 자료의 보관소입니다.

## 핵심 원칙

### 🔒 불변성 (Immutability)
- AI는 이 레이어의 파일을 **절대 수정하지 않습니다**
- 읽기(Read)만 허용됩니다
- 오탈자 발견 시에도 직접 수정하지 않고, 사용자에게 보고합니다

### 📖 읽기 권한
- Ingest 요청 시 소스 파일을 읽고 내용을 분석합니다
- `wiki/sources/`에 요약 페이지를 생성하는 것이 주 목적입니다

## 하위 폴더 구조

| 폴더 | 용도 | 파일명 규칙 |
|---|---|---|
| `articles/` | 웹 아티클, 블로그, 뉴스레터 | Obsidian Web Clipper 자동 생성 |
| `notes/` | 메모, 저널, 아이디어, 대화 정리 | `YYYY-MM-DD_제목-요약.md` |
| `podcasts/` | 팟캐스트, 영상, 강의 트랜스크립트 | `YYYY-MM-DD_제목-요약.md` |
| `research/` | 학술지, 연구 보고서, 데이터셋 | `YYYY-MM-DD_제목-요약.md` |
| `assets/` | 이미지, PDF, 데이터 파일 | 자유 형식 |

## Quartz 빌드
- ❌ **빌드 제외** — `quartz.config.ts`의 `ignorePatterns`에 `"raw"` 포함
- 원본 소스는 내부 참조용이며, 공개 사이트에 노출되지 않습니다

## AI 작업 시 체크리스트
1. ✅ 소스 파일 읽기
2. ✅ 핵심 내용 분석 및 요약
3. ✅ `wiki/sources/`에 요약 페이지 생성
4. ✅ `raw/*/index.md`에 새 소스 목록 추가 (index.md만 수정 가능)
5. ❌ 소스 파일 내용 수정 금지
6. ❌ 소스 파일 삭제 금지
7. ❌ 소스 파일 이동/이름 변경 금지

> **예외**: `index.md` 파일만 AI가 업데이트할 수 있습니다 (목록 관리 목적).
