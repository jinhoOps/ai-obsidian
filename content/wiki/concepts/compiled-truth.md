# Compiled Truth (정리된 진실)

> **"정보의 파편화를 방지하고, 하나의 개념에 대해 '현재 시점의 최선의 이해'를 단일화하여 유지하는 실행 가능한 지식 모델"**

---

## 1. 개념 설명 (비유)
매일 새로운 요리 레시피 아이디어가 떠오를 때마다 새로운 포스트잇에 적어 냉장고 벽에 붙인다고 상상해 봅시다. 시간이 지나면 냉장고 벽은 수십 장의 파편화된 레시피 쪽지로 뒤덮여, 결국 **어떤 요리법이 진짜 최종 버전인지** 알 수 없게 됩니다. 이를 지식 관리에서는 **'기억의 부채(Memory Debt)'**라고 부릅니다.

**Compiled Truth (정리된 진실)**는 냉장고 벽의 쪽지들을 다 버리고, 오직 **'하나의 종합 요리책 페이지'**만 남겨두는 방식입니다.
새로운 레시피 팁(새로운 정보)이 생기면, 새 쪽지를 붙이는 대신 기존 요리책 페이지를 지우고 최신 내용으로 **다시 컴파일(Overwrite/재작성)**하여 항상 단 한 장의 완벽한 최종본만 유지합니다. 대신, 그동안 어떤 팁들을 적용해왔는지에 대한 간단한 변경 이력은 요리책 뒤편의 **'Timeline(타임라인)'**에 덧붙여(Append-only) 둡니다.

```
[ 기존의 파편화 방식 ]                 [ Compiled Truth 방식 ]
┌─────────────────────────┐           ┌────────────────────────┐
│ - 2026-05-10: X 엔진 메모│           │       [ X 개념 ]       │
│ - 2026-05-12: X 수정법  │   ───>    │  현재 최선의 요약/이해 │
│ - 2026-05-15: X 추가 정보│           │  (항상 1개의 완성된 글)│
└─────────────────────────┘           └────────────────────────┘
  (새 메모가 계속 생성되어                     ▲ (새 증거 오면 overwrite)
   지식이 누더기가 됨)                 ┌───────┴───────┐
                                      │   Timeline    │
                                      │ (Append-Only) │
                                      └───────────────┘
```

---

## 2. 정확한 정의
**Compiled Truth** 지식 모델은 지식을 두 개의 뚜렷한 시간적 축으로 이원화하여 관리합니다.

| 레이어 | 속성 | 역할 | 주요 동작 |
|---|---|---|---|
| **Compiled Truth** <br>(정리된 진실) | 가변적, 덮어쓰기<br>(Mutable, Overwrite) | 특정 엔티티나 개념에 대한 **현재 최선의 정밀한 이해(SSOT)** | 새로운 정보가 인입될 때마다 기존 문서를 분석하여 모순 없이 **전면 재작성** |
| **Timeline** <br>(역사적 증거) | 불변적, 추가 전용<br>(Immutable, Append-only) | 해당 진실을 구성하는 데 사용된 **과거의 원시 데이터 및 정보 습득 로그** | 변경하지 않고 습득 시간 순서대로 **차곡차곡 덧붙여 보관** |

---

## 3. 이 모델이 중요한 이유 (지식의 복리 효과)
1. **중복과 모순의 제거**: AI 에이전트와 협업할 때, 동일 주제에 대한 여러 파편화된 파일이 존재하면 AI는 혼란(할루시네이션, 맥락 낭비)을 겪습니다. `Compiled Truth`는 에이전트에게 항상 단 하나의 **'정밀하고 깔끔한 최신 진실'**만 입력으로 제공하므로 의사결정 속도가 획기적으로 증가합니다.
2. **지식 복리 효과 (`[[knowledge-compounding]]`)**: 정보가 들어올 때 쌓이기만(Sprawl) 하는 것이 아니라, 기존 지식과 결합하여 '정제'되므로 지식의 가치가 복리로 성장합니다.
3. **디지털 자아(지식 Proxy) 완성**: 내가 부재중일 때 AI가 나의 지식 베이스를 기반으로 타인에게 답변을 줄 때, 옛날의 틀린 기록이나 오래된 메모를 참조하지 않고 항상 현재 나의 '최종 판단'을 반영하게 만듭니다.
