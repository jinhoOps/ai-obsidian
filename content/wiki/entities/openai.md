# OpenAI

범용 인공지능(AGI) 개발을 목표로 하는 선도적인 AI 기업입니다. GPT 시리즈와 o1 추론 모델 등을 개발하고 있습니다.

## 주요 기여 및 도구
- **ChatGPT / GPT-4**: LLM의 대중화를 이끈 서비스 및 모델.
- **OpenAI o1**: 복잡한 추론 작업을 수행할 수 있도록 설계된 추론 전용 모델 시리즈.
- **MCP (Model Context Protocol)**: 모델과 외부 도구 간의 데이터 교환을 표준화하는 프로토콜.

## 하네스 접근법
- **엔지니어링 중심**: 리포지토리(Repo)를 에이전트의 세계로 구축하고, 린터와 CI를 통해 아키텍처 불변량(Invariants)을 엄격히 강제하는 시스템적 접근을 취함.
