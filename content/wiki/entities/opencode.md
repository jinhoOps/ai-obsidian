# OpenCode

75개 이상의 LLM 모델을 지원하고 프라이버시를 최우선으로 설계된 오픈소스 AI 코딩 에이전트입니다.

## 🔍 개요
- **개발**: SST (Serverless Stack) 팀
- **특징**: 터미널 기반, 모델 자유도, 데이터 미저장(Privacy First)
- **주요 도구**: bash, edit, read, grep, webfetch 등

## 🛠️ 주요 기능
- `/connect`: 다양한 LLM 제공자 연결
- `/init`: 프로젝트 분석 및 `AGENTS.md` 생성
- `@` 문법: 파일 및 서브 에이전트 참조
