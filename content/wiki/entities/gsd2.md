# gsd2 (gsd-2) - v2

## 정의
gsd (v1)의 자율성을 극대화한 차세대 에이전틱 프레임워크입니다. 슬래시 명령어 기반의 제어 방식을 넘어, AI 에이전트가 장시간 스스로 작업을 수행하도록 설계되었습니다.

## 특징
- **자율 실행 에이전트**: 사람의 개입 없이도 목표를 향해 자율적으로 추론하고 실행합니다.
- **실험적 성격**: v1에 비해 커뮤니티 규모가 작고(7.4k★), 아직 실험적인 기능이 많습니다.
- **높은 진입 장벽**: 에이전트가 자율적으로 기동할 수 있는 독립된 환경과 설정이 필요합니다.

## [[gsd]] (v1)와의 차이
| 구분 | gsd (v1) | gsd2 (v2) |
| :--- | :--- | :--- |
| **중심** | 사람의 제어 (CLI 명령어) | 에이전트의 자율성 |
| **검증** | 61k★ (매우 안정적) | 7.4k★ (실험적) |
| **사용성** | 즉시 도입 가능 | 환경 구축 필요 |

## 권장 상황
- 프로젝트 관리와 실행의 안정성이 중요한 일반적인 경우 → **gsd (v1)** 사용.
- 사람의 개입 없이 장시간 자율 실행되는 에이전트 실험이 필요한 경우 → **gsd2 (v2)** 사용.
