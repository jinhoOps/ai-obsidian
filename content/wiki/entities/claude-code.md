# Claude Code

Anthropic에서 개발한 개발자 전용 AI 에이전트 CLI 도구입니다.

## 주요 특징
- **자율적 코드 수정**: 터미널 환경에서 사용자의 명령을 듣고 직접 파일을 읽고, 수정하고, 테스트를 실행함.
- **에이전트 하네스**: 에이전트가 안전하고 일관되게 작업할 수 있도록 설계된 내부적인 가드레일 시스템 포함.
- **에이전트 루프 공식 지원**: 단순히 한 턴씩 묻고 답하는 것을 넘어 `/goal`, `/loop`, `/schedule` 등의 명령어로 목적 중심의 반복 실행이 가능함.
- **오픈소스 포크**: `free-code`와 같은 프로젝트를 통해 멀티 프로바이더 지원 등 실험적인 기능이 확장되기도 함.
