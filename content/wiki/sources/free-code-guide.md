# free-code 설치 및 사용 가이드

Claude Code의 오픈소스 포크 프로젝트인 `free-code`의 특징과 설정 방법을 다룹니다.

## 📌 핵심 내용
1. **멀티 프로바이더**: Anthropic 외 OpenAI Codex, AWS Bedrock, Google Vertex AI 지원.
2. **실험적 기능 해제**: 공식 버전에서 제한된 36개 기능을 기본 활성화.
3. **Telemetry 제거**: 사용자 데이터 수집이 없는 순수 실험 환경 제공.
