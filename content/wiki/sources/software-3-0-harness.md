# Software 3.0 시대의 하네스와 조직 생산성

AI가 소프트웨어 개발의 핵심이 되는 Software 3.0 시대에 조직의 생산성을 높이기 위한 하네스 전략을 다룹니다.

## 핵심 내용

1. **[[executable-ssot|실행 가능한 SSOT]]**: 문서를 단순한 기록이 아닌, LLM이 즉각 수행할 수 있는 시스템 프롬프트이자 매뉴얼로 전환.
2. **Raising the Floor**: 팀 내 AI 활용 역량의 편차를 줄이기 위해 도메인 맥락이 담긴 워크플로우를 플러그인화하여 배포.
3. **지식의 계층화**: 조직/도메인, 프로젝트, 작업/기능 계층으로 지식을 분리하여 LLM에 필요한 만큼만 주입.
