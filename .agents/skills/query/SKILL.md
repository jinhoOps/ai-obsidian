# /query — LLM Wiki 질문·탐색 스킬

> 사용자의 질문을 받으면 `content/wiki/`의 문서를 체계적으로 탐색하여 **근거 기반의 답변**을 합성합니다.
> 벡터 DB가 아닌, AI가 직접 위키 페이지를 읽고 연결하여 답변하는 방식입니다.

---

## 🛡️ 불변 규칙 (Invariants)

1. **답변의 모든 근거는 wiki/ 페이지에서 나와야 한다.** 출처 없는 주장은 금지.
2. **위키에 없는 정보는 "위키에 아직 없습니다"라고 솔직히 말한다.**
3. **웹 검색으로 보충할 때는 `⚠️ 위키 외 정보`로 표시한다.**
4. **`content/raw/`는 읽기 전용이다.**
5. **가치 있는 답변은 위키 페이지로 저장하여 지식을 복리로 쌓는다.**

---

## 📋 워크플로우: UNDERSTAND → NAVIGATE → SYNTHESIZE → ENRICH

### Phase 1: UNDERSTAND (질문 이해)

질문을 5가지 유형으로 분류하여 탐색 전략을 결정합니다:

| 유형 | 탐색 전략 | 예시 |
|---|---|---|
| **LOOKUP** | 단일 페이지 직접 조회 | "gstack이 뭐야?" |
| **COMPARE** | 복수 페이지 병렬 조회 → 비교 표 | "gstack vs superpowers?" |
| **CONNECT** | 위키링크 그래프 순회 → 패턴 도출 | "AI 에이전트 도구들의 공통점?" |
| **APPLY** | 개념 + 사용자 맥락 결합 | "Stock Snowball에 TDD를 어떻게?" |
| **GAP** | 전체 스캔 → 공백 식별 | "마이크로서비스 정보 있어?" |

### Phase 2: NAVIGATE (위키 탐색)

`content/wiki/index.md`를 시작점으로 깊이 우선 탐색합니다:

```
1. wiki/index.md 읽기 → 질문 키워드와 매칭되는 [[페이지]] 식별
2. 매칭된 페이지 읽기 (1차 탐색) → 답변 정보 수집 + 추가 [[위키링크]] 후보
3. 위키링크 따라가기 (2차 탐색, 필요 시) → 최대 깊이 2단계
4. 원본 소스 참조 (3차 탐색, 필요 시) → content/raw/ 원본 확인
```

- **최소 읽기 원칙**: 답변에 충분하면 더 이상 읽지 않습니다.
- **병렬 읽기**: 독립적 페이지는 동시에 읽습니다.

### Phase 3: SYNTHESIZE (답변 합성)

#### 출력 규칙
- 모든 정보에 `[[위키링크]]` 출처를 명시합니다.
- 위키 외 정보는 `> ⚠️ 위키 외 정보`로 구분합니다.

#### 질문 유형별 출력 형식

| 유형 | 출력 형식 |
|---|---|
| LOOKUP | 핵심 정의 + 특징 목록 + 관련 링크 |
| COMPARE | 마크다운 비교 표 + 강점/약점 |
| CONNECT | Mermaid 다이어그램 + 관계 설명 |
| APPLY | 단계별 가이드 + 구체적 예시 |
| GAP | "위키에 없습니다" + 소스 수집 제안 |

#### 답변 구조
```markdown
### 📖 답변
{핵심 답변 1-3문장}

#### 상세 설명
{근거 기반 상세. [[위키링크]] 활용}

#### 참조한 위키 페이지
- [[페이지1]] — {가져온 정보 요약}
```

### Phase 4: ENRICH (지식 환류)

다음 조건에 해당하면 위키 저장을 제안합니다:

| 조건 | 저장 경로 |
|---|---|
| 여러 페이지를 연결한 새로운 통찰 | `wiki/synthesis/` |
| 두 대상의 비교 분석 | `wiki/comparisons/` |
| 페이지 없이 언급만 된 개념 | `wiki/concepts/` |
| 프로젝트 적용 계획 | `wiki/synthesis/` |

- 사용자 승인 후: 페이지 생성 + `index.md` 업데이트 + `log.md` 기록
- 거절 시: 답변만 제공, 위키 변경 없음

## 🔧 엣지 케이스

| 상황 | 처리 |
|---|---|
| 위키가 비어있음 | `/ingest` 실행을 안내 |
| 관련 페이지 없음 | 가장 가까운 페이지 제시 + 소스 수집 제안 |
| 질문이 모호함 | 해석 2-3가지를 제시하고 되물음 |
| 위키 정보 부족 | 위키 기반 답변 후 부족한 부분 명시 |
