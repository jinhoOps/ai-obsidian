# /lint — LLM Wiki 건강 검진 스킬

> 위키를 도서관이라 하면, `/lint`는 정기적으로 서가를 돌며 잘못 꽂힌 책을 바로잡고,
> 찢어진 라벨을 고치고, 아무도 찾지 않는 책을 눈에 띄게 배치하는 **사서**입니다.

---

## 🛡️ 불변 규칙 (Invariants)

1. **`content/raw/`는 절대 수정하지 않는다.**
2. **`content/wiki/`는 AI가 소유한다.** 이 스킬이 수정할 수 있다.
3. **파괴적 변경(삭제, 대규모 구조 변경)은 사용자 승인 후에만 수행한다.**
4. **모든 수정은 `content/wiki/log.md`에 기록한다.**

---

## 📋 워크플로우: SCAN → DIAGNOSE → FIX → VERIFY

### Phase 1: SCAN (전수 조사)

`content/wiki/` 하위 모든 페이지를 읽고 **7가지 검사**를 수행합니다:

| # | 검사 항목 | 심각도 | 자동 수정 |
|---|---|---|---|
| 1 | 🔗 **깨진 링크** — 존재하지 않는 `[[위키링크]]` | 🔴 HIGH | ⚠️ 일부 |
| 2 | 🏝️ **고아 페이지** — 아무 데서도 링크되지 않는 페이지 | 🟡 MEDIUM | ❌ 수동 |
| 3 | 👻 **유령 개념** — 언급만 되고 자체 페이지가 없는 개념 | 🟡 MEDIUM | ✅ 가능 |
| 4 | 📋 **Frontmatter 오류** — 필수 필드 누락, 타입/날짜 형식 오류 | 🔴 HIGH | ✅ 가능 |
| 5 | 📇 **인덱스 불일치** — `index.md`와 실제 파일 불일치, 통계 오류 | 🔴 HIGH | ✅ 가능 |
| 6 | 🕐 **낡은 내용** — 새 소스 인제스트 후 미반영된 기존 페이지 | 🟡 MEDIUM | ⚠️ 일부 |
| 7 | 🔍 **지식 공백** — 비교 부재, 종합 부재, 미인제스트 소스 | 🟢 LOW | ❌ 수동 |

**Frontmatter 필수 필드**: `title`, `type`, `tags`, `sources`, `created`, `updated`, `draft`

### Phase 2: DIAGNOSE (진단 보고)

발견된 문제를 심각도별로 분류한 **진단 보고서**를 생성합니다:

```markdown
# 🏥 위키 건강 검진 보고서
> 검진 일시: {날짜} | 범위: {N}개 페이지

## 📊 요약 대시보드
| 검사 항목 | 발견 | 심각도 | 자동 수정 |
|---|---|---|---|
| ... | {N}건 | ... | ... |

**건강 점수: {0-100}점**
```

#### 건강 점수 = `100 - (HIGH × 10) - (MEDIUM × 3) - (LOW × 1)`

| 점수 | 등급 |
|---|---|
| 90-100 | 🟢 건강 |
| 70-89 | 🟡 주의 |
| 50-69 | 🟠 경고 |
| 0-49 | 🔴 위험 |

### Phase 3: FIX (수정)

#### 자동 수정 (승인 불필요)

| 항목 | 수정 방법 |
|---|---|
| Frontmatter 누락 필드 | 기본값 추가 |
| 인덱스 누락/유령 항목 | 실제 파일 기준으로 동기화 |
| 통계 오류 | 실제 수 집계 후 업데이트 |
| 날짜 형식 오류 | `YYYY-MM-DD`로 정규화 |

#### 수동 승인 (선택지 제시)

- **깨진 링크**: 페이지 생성(stub) / 링크 수정 / 링크 제거
- **고아 페이지**: 관련 페이지에 링크 추가 / draft로 변경 / 삭제 / 무시
- **유령 개념**: 페이지 생성 / 무시
- **낡은 내용**: 업데이트 / 무시
- **지식 공백**: 비교·종합 페이지 생성 / 무시

#### 일괄 옵션
- `모두 자동 수정` — 자동 가능 항목 일괄 처리
- `HIGH만 수정` — 심각도 HIGH만 처리
- `하나씩 확인` — 각 항목 개별 검토 (기본값)

### Phase 4: VERIFY (검증)

1. 수정된 페이지를 대상으로 검사를 재수행합니다.
2. `content/wiki/log.md`에 lint 기록을 추가합니다:
   ```markdown
   ## [{날짜}] lint | 위키 건강 검진
   - **건강 점수**: {이전} → {수정 후}
   - **발견 / 수정**: 깨진링크 {N}/{N}, Frontmatter {N}/{N}, ...
   - **잔여 문제**: {N}건
   ```
3. 수정 전/후 비교 표를 포함한 완료 보고서를 제출합니다.

## 🔧 엣지 케이스

| 상황 | 처리 |
|---|---|
| 위키가 비어있음 | `/ingest` 실행 안내 |
| 문제 0건 | "🎉 완벽한 상태!" + 다음 lint 권장 시점 |
| `index.md` 자체 손상 | 파일 시스템 기준으로 재생성 (사용자 확인 후) |
| 50+ 페이지 대규모 위키 | 카테고리별 순차 스캔 + 중간 진행 보고 |
